# Contributing

Read [AGENTS.md](AGENTS.md), the [project direction](docs/project-direction.md)
and the [capture contract](docs/capture-format.md). Keep changes focused on a
useful recording or analysis workflow. Run `pwsh -File scripts/verify.ps1`.

Use synthetic data for tests. Report actual recorder overhead measurements with
their environment and workload; do not equate elapsed timing with CPU attribution.
Record in-game evidence separately from standalone tests.

Questions, documentation and reproducible bug reports are welcome. Search issues,
discuss substantial changes first, then fork and open a focused pull request.
Explain the problem, resulting behaviour, checks and remaining limits. Original
contributions are MIT licensed; retain third-party terms and attribution.

Follow [community expectations](CODE_OF_CONDUCT.md). Use synthetic captures in
reports; redact private data. See [SUPPORT](SUPPORT.md) and [SECURITY](SECURITY.md).
Package publication remains a separate action from public source access.
